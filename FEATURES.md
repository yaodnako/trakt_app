# Trakt Tracker Features

## Desktop

- Trakt auth
- Search
- History
- Ratings
- Progress
- Upcoming
- Notifications
- Settings
- Play flow

## Web

- `Progress`
- `History`
- `Search` with poster artwork, provider rating chips, personal rating badges, play actions, outside mark-watched actions, and show watch-panel entry
- `Settings`
- Title details page
- Shared modal rating flow for web History, Search, and Progress
- Show-level episode ratings matrix overlay

## Shared UX Capabilities

- Shared title and episode metadata from SQLite-backed caches
- Queue-driven in-place refresh for web `History` and `Progress`
- Title-level rating chips and show-level episode matrix access
- IMDb and Trakt rating presentation where data exists
- Manual sync actions from the web settings screen
