Trakt Tracker 0.2.0 beta 1 (Windows x64)
================================================

1. Extract the entire ZIP archive to a normal folder.
2. Double-click TraktTracker.exe. The portal opens in your default browser and
   continues running in the Windows system tray after the browser is closed.
3. Use the tray menu to open, restart, or quit the portal.

The portal is available only on this computer. It does not add a Windows
Firewall rule and does not expose the web interface to the local network.

Profiles, tokens, databases, caches, and settings are stored under
%LOCALAPPDATA%\TraktTracker and are not removed when the portable folder is
replaced. To update: choose Quit in the tray, extract the new version, and run
the new TraktTracker.exe. If autostart is enabled, launching the moved EXE once
updates its saved path.

This beta is unsigned, so Windows SmartScreen can display an unknown publisher
warning. There is no automatic updater in this version.
